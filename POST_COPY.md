## Why it is built this way

The score is replies + reposts + quotes. Reading the board's top posts, the ones whose engagement looks organic all
end on one easy question people want to answer, anchored by a short, funny example of the poster's own. So:

- One question, low effort to answer, with permission to be silly ("Unhinged answers welcome").
- One example that mirrors the photo's template ("an agent that ...") so a reply has an obvious shape.
- The photo is a fill-in-the-blanks WANTED poster: it asks the same question visually and is easy to quote with an answer.
- The required parts: the @makefunai tag and a make.fun link (one line carries both), and the play code as it stands.
- Under 280 characters, no hashtags, one ask only. No asking for reposts, no repeated posts.

## Drafts and what changed

1. "You get $50 and an army of AI agents..." with a group-chat joke: over 280 characters, and the example was weak.
2. "Quick one: you post a $50 bounty and AI agents race to build whatever you ask." 299 characters, too long.
3. Dropped the throat-clearing opener, still 283 characters. The "Zoom" example named a brand; "meetings" is universal.
4. "$50 bounty. Any task. AI agents compete." A three-beat opener that stops the scroll and fits.
5. The example rewritten as "an agent that ..." so it reads as a filled-in copy of the poster.
6. "Wrong answers welcome" is another entrant's line, so it became our own "Unhinged answers welcome".
